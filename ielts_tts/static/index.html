How a session works

  1. Copy the prompt on a channel page. Add a note if you like ("make it hard").
  2. Paste it into Claude. Claude writes the script, questions and answer key in one code block.
  3. Paste Claude's reply back. The format check makes sure the app can voice and mark it.
  4. Generate, then sit it in Exam (plays once) and review it in Practice.
