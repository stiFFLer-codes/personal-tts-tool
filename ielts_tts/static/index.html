Master IELTS Listening, one Part at a time

Pick a Part to drill, or sit a Full Test. Each task gives you an exam-accurate prompt for Claude, turns Claude's script into exam audio and marks you like the real test.

How it works

  1. Copy the prompt on a task page (pick a topic and question type, or keep the real exam mix).
  2. Paste it into Claude. Claude replies with one code block: script, questions and answer key.
  3. Paste Claude's reply back into the task page. The format checklist makes sure it matches the real exam.
  4. Generate the audio, then sit it in Exam mode (plays once) and review in Practice.
